# Inmobiliaria CRM

Micro app multiempresa que centraliza los mensajes de WhatsApp, Instagram, Messenger y el chat de la web en un módulo de Leads (resumen con IA, reparto entre asesores por oficina, avisos y derivación). Pensada para venderse a varias inmobiliarias, cada una independiente de las otras.

**Para entender el proyecto: `docs/LEEME-PRIMERO.md`.**

```bash
npm ci
npm run typecheck
npm test
npm run dev
```
